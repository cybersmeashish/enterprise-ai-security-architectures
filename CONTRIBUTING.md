# Contributing

Start with a specific problem, an owned/authorized synthetic reproducer and an expected boundary. Include a valid case, a denied/failure case, source/version/configuration, actual result and limitation.

For a new adapter, prove destination identity, credential handling, error/usage semantics, bounded retries and residency-safe fallback. For a governance contribution, identify the accountable decision, artifact/test links and remaining gap; cite primary sources and distinguish interpretation.

Do not include secrets, customer data, restricted documents or unverifiable credentials/claims. Avoid claiming a feature is implemented until its evidence is inspectable. See [SECURITY.md](SECURITY.md) for confidential findings.
