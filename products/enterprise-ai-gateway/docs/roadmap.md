# Roadmap toward enterprise assurance and 2030

The 2030 direction is a portfolio of inspectable enterprise AI security architecture, governance and sovereign-operation evidence. These are planned gates, not delivery promises or shipped capabilities.

| Sequence | Product increment | Evidence required before announcing it |
|---|---|---|
| Next | Enterprise identity and one real provider adapter | Issuer/audience tests, credential rotation, TLS/destination identity, usage reconciliation |
| Next | Independently anchored evidence and protected signer custody | Tamper/truncation exercises, time uncertainty, custody and recovery |
| Then | Real RAG store and representative model evaluation | Live ACL changes, source-grounded quality, cohort fairness and calibrated privacy tests |
| Then | Distributed data-plane state | Partition-safe quotas, idempotency, approval/recovery and HA load tests |
| Then | MCP and scoped agent interoperability | Current protocol conformance, downstream audience, delegation and approval revocation |
| Then | Sovereign/disconnected learned-model pilot | Full dependency/import inventory, observed placement, offline identity and recovery |
| Long-term | Cryptographic transition and industry pilots | Maintained implementation compatibility, archival verification and accountable sector-specific evaluation |

Each contribution should answer a specific research question, produce code or a decision artifact, link to primary sources and include at least one negative case. Publish unsuccessful hypotheses with their operational consequence. Influence should follow useful evidence and collaboration.
