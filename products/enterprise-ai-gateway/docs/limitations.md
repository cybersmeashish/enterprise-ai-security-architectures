# Known limitations and risk disclosures

This is a security reference preview, not an enterprise service.

1. Providers are deterministic loopback HTTP fixtures. There is no learned model, real provider adapter, streaming, embeddings, reranking or multimodal contract.
2. Credentials are generated by a demo in-memory issuer. No enterprise SSO, JWT/OIDC validation, federation or durable identity restore is present.
3. DLP checks are narrow regex fixtures. Obfuscated emails pass. Input inspection does not solve prompt injection.
4. Region is declared registry metadata. No cloud placement, residency, support path or backup location is attested.
5. SQLite is local, not an HA distributed quota or idempotency system. The server caps concurrent handlers but has no enterprise ingress protection.
6. Response replay is encrypted under a default ephemeral key; restart without that key prevents replay. TTL deletion is opportunistic and is not physical secure erasure.
7. Audit is metadata-only but remains potentially sensitive. The local hash chain cannot detect suffix deletion or privileged recomputation without an independent anchor.
8. Running idempotency records remain blocked after a crash; operator recovery is needed. Failed/ambiguous provider attempts remain reserved in demo credits.
9. Tool actions affect only synthetic records. Existing grants are not revoked when a reviewer credential is later revoked.
10. A whole-store rollback can restore old policy watermarks. Production rollback resistance needs independent trusted state.
11. Model quality, fairness, factuality, calibrated privacy detection, Kubernetes operation, real-provider latency and large-scale inference capacity remain unmeasured.
12. Regulatory mappings are assessment aids. No certification, legal advice, customer adoption, deployment or commercial support agreement is claimed.

Tests explicitly retain the regex, audit-truncation and unsafe-consumer examples so these gaps remain visible. [Roadmap](roadmap.md) prioritizes the next evidence rather than hiding uncertainty.
