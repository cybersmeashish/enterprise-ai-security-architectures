# Model approval card

**Synthetic example:** local-standard, synthetic-v1, deterministic HTTP fixture; intended use: test the gateway's contracts. No learned-model capability, training dataset, accuracy or safety performance is implied.

For a real model record provider/version/digest, source/provenance, license, intended and prohibited use, supported capabilities, training/fine-tune lineage where known, known limitations, evaluation cohort/results, region/retention/support declaration, supplier risk, owner, independent approval, expiry and retirement.

Approval gate: representative quality, fairness, privacy and security results must exist. A reachable endpoint is not an approved model.
