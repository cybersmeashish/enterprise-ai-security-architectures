# Capacity, service indicators and SLO record

**Synthetic example:** 60 uncached HTTP requests per cohort at concurrency 1/4/8; deterministic provider; local SQLite. No enterprise SLO is established.

Record hardware/CPU/memory, image and source hashes, provider/version/network, input/output distribution, streaming share, concurrency/queue, warmup, duration, successes/errors, latency distribution, state I/O, cost and saturation.

Separate gateway availability, eligible-route availability, useful-task quality and end-to-end completion. Define owner, objective, window, error budget and action. Test overload, partition, disk and recovery; a replica count is not a reliability proof.
