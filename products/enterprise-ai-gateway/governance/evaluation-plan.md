# Model and gateway evaluation plan

**Synthetic example:** 92 gateway regression cases and 12 operational scenarios; deterministic providers. These establish selected runtime behavior, not task quality.

Version the model/provider/API, policy, prompt, retrieval corpus and dataset. Define authority oracle, quality reference, human reviewers, cohorts/languages, privacy labels, fairness/context metrics, failure severity, pass threshold and uncertainty before measurement.

Record unsuccessful cases. High-impact authorization or safety failures block promotion even if the average score improves. Govern any production sampling and content capture.
