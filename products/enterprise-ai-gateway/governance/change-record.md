# Model, policy and configuration change record

**Synthetic example:** revision 1; site lab-site-a; owner security-governance; admitted under an ephemeral demo signer. This is not production approval.

Capture change intent, exact diff, artifact digest, use cases/risks affected, proposer, independent reviewer, tests, evaluation, signer/trust input, rollout scope, expiry, monitoring, rollback/forward-recovery and decision.

Changing the digest at an existing revision is rejected locally. Production rollback uses a new reviewed revision and a separately protected trusted watermark.
