# Security reporting and supported scope

Version 0.1.0 is a local security-reference preview using synthetic providers/data. It is not approved for a real-data production deployment.

Report security defects through [GitHub private vulnerability reporting](https://github.com/cybersmeashish/enterprise-ai-security-architectures/security/advisories/new). Provide affected version/commit, boundary, synthetic reproducer, impact and minimal evidence. Keep secrets or customer information out of public issues.

This repository's own synthetic environment is intended for testing. Its existence does not authorize testing third-party services. See [known limitations](products/enterprise-ai-gateway/docs/limitations.md).
